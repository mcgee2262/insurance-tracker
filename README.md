# Insurance Quote Tracker

A one-page site for comparing car insurance quotes (Virginia Farm Bureau, Travelers, Erie) against what we pay GEICO now.

- Plain HTML, CSS and JavaScript. No build step.
- Quotes save in your own browser (`localStorage`, key `insuranceTracker`). Nothing personal is stored in this repo.
- To add a company, add one object to the `insurers` array in `app.js` and drop its logo in `assets/logos/`.

Run locally: open `index.html` in a browser.

Logos are trademarks of their respective companies. Personal use only. The GEICO logo is the site's favicon, because geico.com blocks automated downloads.
